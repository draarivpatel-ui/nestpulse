# NestPulse | UGREEN Hackathon 2026 on AI NAS

Name: NestPulse, a command center for a personal AI NAS

Description:
NestPulse is a browser dashboard for planning and running a self hosted storage box, built for the Automate Your Workflow track.

Storage Doctor answers the drive questions first: usable space, efficiency, and rebuild windows for every RAID level, with the math shown on each card. Model Fit checks which open weight models fit a RAM or VRAM budget across seven quantization levels before you download anything. Tidy Plans runs a cleanup simulation over a labeled synthetic library, ranking duplicate groups and space savings by confidence, never proposing the same file twice. Rule Forge builds home automation rules and then hunts for trouble, flagging contradictions, shadowed rules, and unknown sensors before deployment, and dry runs everything against seventy two hours of synthetic logs.

Everything computes locally in the browser with no backend. All datasets are labeled synthetic, no hardware or vendor relationship is claimed, and seventy nine unit tests cover the RAID math, model fit arithmetic, dedupe ranking, and rule conflict detection.

Built with: vanilla JavaScript, node:test.
